# Нейроподарки

Прототип ИИ-сервиса дарения подарков для витрины подарков OK: пользователь в три шага выбирает картинки-теги, и из них собирается промт для генерации подарка.

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | **Нейроконструктор** — автономная страница: все 66 картинок встроены внутрь, открывается двойным кликом. Табы «Конструктор» и «Промты», переключатель модели Nano Banana / Qwen. |
| `images/` | Исходные картинки карточек (PNG), по одной на категорию, вид, локацию и аксессуар. |
| `prompts/prompts.json` | Все тексты промтов в машиночитаемом виде: промт карточки, текст сцены, окружения, стили для обеих моделей, negative prompt для Qwen. |
| `backup/` | Бэкап от 29.10.2026: версия конструктора с полными промтами до сокращения и JSON с теми же текстами. |

## Как устроен промт

Категории: **Цветы, Торт, Сердце** (предмет + добавление + окружение) и **Котёнок, Коза, Медвежонок** (персонаж + локация + аксессуар).

У каждой карточки два текста:
- **промт карточки** — для отрисовки самой иконки, предмет отдельно («shown as a standalone…»);
- **сцена** — как этот предмет входит в итоговую картинку (окружение, поза, что держит).

Режимы сборки итогового промта:
- **Nano Banana** — длинный промт: описание персонажа, сцена, аксессуар, развёрнутый стиль.
- **Qwen** — персонаж приходит картинкой-референсом, поэтому текстом не описывается. Порядок: «персонаж с референса» → окружение → аксессуар → взгляд в камеру → короткий стиль без отрицаний. Отдельно — negative prompt.

## Правила, к которым пришли

- Окружение описывается всегда и конкретно, иначе модель рисует пустой студийный фон.
- Персонажи сидят/стоят «по-человечески» и смотрят в камеру.
- Для Qwen: сцена в начале промта, никаких «not / never» в основном тексте (уходят в negative), композиция по центру.
- «Square 1:1», «no watermark, no logo» не пишем — формат и так квадратный.
